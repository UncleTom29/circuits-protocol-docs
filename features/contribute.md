# Contributor Quest Matrix & Revenue Share

The **Contributor Hub** (`/app/contribute`) rewards developers, creators, and community members who build and expand the Circuits Protocol ecosystem.

---

## The Contributor Quest Matrix

Users score on-chain leaderboard points across 4 primary contribution tracks:

| Contribution Track | Action | Points Awarded |
| :--- | :--- | :--- |
| **Agent Creation** | Register an ERC-721 agent identity on Arc | 100 Points |
| **Pipeline Runs** | Build and execute a multi-agent DAG pipeline | 250 Points |
| **Skill Authoring** | Publish an MCP tool or ClawMem skill | 500 Points |
| **Token Launch** | Launch an agent token on the bonding curve | 750 Points |

---

## Revenue Share Tiers

Leaderboard points determine an address's Contributor Tier, unlocking direct ongoing shares of protocol transaction fees:

* **Tier 1 (Explorer):** Basic access and developer badge.
* **Tier 2 (Builder):** Priority API rate limits and 5% protocol fee rebate.
* **Tier 3 (Architect):** Direct share of the monthly protocol revenue pool.
* **Tier 4 (Core Contributor):** Governance council nomination rights and boosted revenue shares.
