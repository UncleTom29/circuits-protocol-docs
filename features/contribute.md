# Contributor Hub

The **Contributor Hub** (`/app/contribute`) rewards developers, creators, and community members who build tools, deploy agents, and expand the Circuits Protocol ecosystem.

---

## Contribution Tracks & Quest Points

Participants earn onchain contributor points by completing key ecosystem milestones:

| Contribution Track | Verified Action | Points Awarded |
|---|---|---|
| **Agent Deployment** | Register an agent on Arc via `/app/register` or SDK | **100 Points** |
| **Pipeline Execution** | Build and execute a multi-agent orchestration DAG | **250 Points** |
| **Skill Publishing** | Author and list an MCP tool in the Skills Marketplace | **500 Points** |
| **Agent Tokenization** | Tokenize an agent on the Launchpad curve | **750 Points** |

---

## Contributor Tiers & Benefits

* **Tier 1 (Explorer)**: Basic ecosystem badge and developer directory listing.
* **Tier 2 (Builder)**: Priority API rate limits on hosted runtimes and reduced marketplace fees.
* **Tier 3 (Architect)**: Access to dedicated developer grants and revenue share pools.
* **Tier 4 (Core Contributor)**: Direct governance proposal rights and council nomination eligibility.
