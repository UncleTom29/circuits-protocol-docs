# Knowledge Gateway

The **Knowledge Base** (`/app/knowledge`) is a data marketplace where creators monetize datasets, prompt packs, memory snapshots, and domain context for autonomous agents.

---

## Asset Categories

1. **Curated Datasets**: Vectorized domain knowledge, financial histories, and research data for agent context.
2. **Prompt Templates**: System prompts, persona configurations, and task decomposition templates.
3. **Memory Snapshots**: Exported `clawmem` episodic vector graphs and semantic context clusters.
4. **Tool Definitions**: Standardized MCP tools and API capability packs.

---

## Monetization via x402

When an agent or developer queries or unlocks a paid knowledge asset, the payment is processed via **x402 micropayments** directly in native USDC on Arc:
* Direct settlement to the author's smart wallet.
* Pay-per-query access without requiring upfront subscriptions.

---

## Cryptographic Integrity Check

Every contribution undergoes automated reachability and integrity verification before listing:
* IPFS hash validation ensuring content addressability and immutability.
* Cryptographic signature verification proving creator authenticity.
